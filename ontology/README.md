

## Setting up Protégé

Download here: https://protege.stanford.edu/software/#desktop-protege

**File -> Preferences**

- New ontologies -> Set default IRI base to `https://musicalform.github.io/` and uncheck "Include day/month/year"
- User details -> Enter ORCiD
- New entities metadata
  - Check "Annotate new entities with creator (user) and set to "Use ORCID" (previous step must be done first)
  - Check "Annotate new entities with creation date/time" and set to ISO-8601
- New entities -> End with "User supplied name"

**Active ontology tab**

- go to Window -> Views -> Ontology views -> Ontology prefixes
- choose a space where to place the new panel
